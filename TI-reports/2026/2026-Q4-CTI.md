# 2026 Q4 Core Toolchain Infrastructure Project (CTI)

## Overview

Core Toolchain Infrastructure Project (CTI) continues to work towards providing state of the art secure infrastructure for the GNU Toolchain and ancillary projects.

As a project we presented at OpenSSF's Community Day in Prague with a [keynote highlighting we have 3 new sponsors](https://www.youtube.com/watch?v=LT6OwK077YQ&list=PLDEhySvXRac0&index=2) for the associated directed fund to support improvements and services in CY27 and CY28. We continue to work with a larger set of sponsors to reach our target of 8 Premier sponsors for the fund.

In CY26Q4 the work continues to focus on supporting the GNU C Library (one of 4 core GNU Toolchain projects) to migrate services to CTI.

Since CY26Q3 the project has continued to hold weekly Friday office hours and completed the following:

 * Split the [service transition plan](https://sourceware.org/glibc/wiki/service-transition-plan) into multiple stages.
 * Currently 4 RFCs with the community to improve supply chain security and robustness:
     * [\[RFC\] Using bugspray for updating glibc bugs in bugzilla?](https://inbox.sourceware.org/libc-alpha/a1c0fb87-de0f-40da-a917-25520839d209@redhat.com/)
     * [\[RFC\] Using git-mailbomb as post-commit VCS to email system for glibc-cvs emails?](https://inbox.sourceware.org/libc-alpha/5d2ef95d-94c4-40aa-83a7-84dc5f376e2b@redhat.com/)
     * [\[RFC\] Using project and service specific DNS end points to support flexible deployments.](https://inbox.sourceware.org/libc-alpha/8e167d49-86c5-45ba-841d-f9f74151d596@redhat.com/T/#u)
     * [\[RFC\] Provide horizontally scaled git pull mirrors for the GNU Toolchain, starting with glibc.](https://inbox.sourceware.org/libc-alpha/272e308a-a703-4824-b823-cd8e5266f00b@redhat.com/)
 * Worked with the service provider to implement one RFC, namely a horizontally scaled read-only git pull mirror.
     * Service is online at [https://git.glibc.coretoolchain.dev/glibc](https://git.glibc.coretoolchain.dev/glibc)
     * Service testing has started showing ~15% performance improvement in NA (US East Coast), and ~600% in APAC (India testing).
     * Additional geodns nodes in EU are supporting India developers working with upstream directly instead of using untrusted mirrors.
 * Testing VM to process git to bug tracker update (bugspray RFC), which can be handed to CTI's service provider.
     * Worked with [community](https://inbox.sourceware.org/libc-alpha/58f21418-55f8-4ea3-b42b-1b935e4d4387@redhat.com/) to design regexps.

## Core Toolchain Infrastructure Project 

Core Toolchain Infrastructure Project (CTI) in 2026 Q4 continues to move forward secure development practices, but now in direct support for the GNU C Library (glibc) as the first GNU Toolchain project to migrate to new CTI services.

In order to engage the developers and discuss the transition the CTI TAC continues to hold weekly Friday office hours for the migration.

The current service transition plan has been split into multiple RFCs for review and transition with the community.

### Purpose

The Core Toolchain Infrastructure (CTI) Project’s mission is to support the GNU Toolchain community with secure infrastructure and state of the art services required to support the community’s development efforts to be a trusted foundation in a secure supply chain.

The CTI project continues to move forward the goal of creating a long-term sustainable set of secure and state of the art services and infrastructure for the GNU Toolchain and related packages.

Some of the major goals include:

 * Secure and state of the art infrastructure.
 * Continuity planning for infrastructure, development, and governance.
 * Security policy planning.

### Current Status

 * Working with Linux Foundation IT to implement each incremental RFC from November to December 2026.
 
### Up Next

 * Submit additional RFCs including one for email.
 * Engage an additional 5 sponsors (of the 18 identified) in CY26Q3-Q4 for CY27 and CY28.

### Funding requests and updates

The Core Toolchain Infrastructure project as a Linux Foundation ADF was already granted funding and has been using this funding to support the service transition.

The remaining funding for CTI will be spent in CY26Q3-Q4 to transition the glibc services to CTI.

Sponsors for CTI are directed to email the TAC at cti-tac@lists.linuxfoundation.org, or to directly review the [ADF in LFX](https://enrollment.lfx.linuxfoundation.org/?project=cti).
